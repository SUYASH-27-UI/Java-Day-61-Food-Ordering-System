# Online Food Ordering & Billing System – Java Day 61

## Description
A Java application that allows users to browse a food menu, add items to a cart and generate bills automatically.

## Features
- Display available food items
- Add items to shopping cart
- Select item quantities
- View cart details
- Calculate subtotal and GST
- Generate final bill
- Save completed orders in a text file

## Technologies
- Java
- ArrayList
- Object-Oriented Programming
- File Handling

## Files
- `Main.java`
- `orders.txt` – generated automatically

## How to Run
```bash
javac Main.java
java Main
```

## Concepts Used
Classes, Objects, Constructors, ArrayList, Object Composition, File Handling and Billing Calculations.

**Note:** This is an educational food ordering simulation. It does not process real payments.
